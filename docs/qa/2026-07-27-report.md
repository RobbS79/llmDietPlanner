## Refine chat v2 — defect summary (evidence)

1. **JSON leak into chat bubbles** (5/6 turns). Example visible text:
   `Rozumím, najdu ti něco jiného k obědu. Co bys řekl na kuřecí stroganov s noky? Je to syté a chutné jídlo.{"reply": "…", "candidate_id": "18944"}`
   Raw API: `reply_text` contains the concatenated prose+JSON, `candidate: null`, `research_job_id: null`.
2. **Candidate cards never surface** ⇒ the primary swap flow of the feature is unusable from the UI. Accept machinery itself is fine (verified via API).
3. **Phantom web search**: assistant claims it is searching the internet while no research job is created (no spinner, no poll). Only 1/6 turns actually invoked the tool; that job failed curation (honest failure copy — good) so no end-to-end web-recipe acquisition was ever demonstrated.
4. Suspected fixes: make `_parse_final` extract a trailing/embedded JSON object from mixed prose+JSON output, accept string `candidate_id`, and tighten the tool-use prompt so "search the web" narration is only produced after the `web_research` tool call.
