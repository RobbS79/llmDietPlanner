## Failing rows (NO-GO drivers)

1. **Generation crash + raw-error failure screen** — `recipe_retrieval.py:686` (`_calorie_targets_from_days`) assumes `nutritional_info` is a dict; a string from Gemini crashes the whole task. User sees "GENEROVÁNÍ SELHALO: Meal plan generation failed: 'str' object has no attribute 'get'" even though the retry quietly succeeds. Fix is a one-line guard (`isinstance(ni, dict)`), plus ideally not surfacing raw exceptions / not declaring failure while a retry is pending.
2. **Per-portion amounts implausibly small** — 16 kcal breakfast, 684 kcal/day average; ingredient lists scaled to 1/12-recipe fractions (0,5 vejce, 0,25 lžičky ×7) while steps retain whole-recipe amounts.
3. **Refine/replace dead-ends** after promising a web search — swap flow effectively broken for any request the corpus can't satisfy.
